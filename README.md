House Occupancy Prediction

Project Overview

This project predicts whether a house or room is occupied or unoccupied using Machine Learning algorithms.

Input Features

- Temperature
- Humidity
- Light
- CO2

Machine Learning Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Project Objective

To predict house occupancy based on environmental sensor readings.
